# GG Game Space
Native Kotlin Android starter with a RedMagic-inspired black/red gaming dashboard.

Included: game picker/launcher, home dashboard, FPS preference profiles (60/90/120/144/160/device-supported), Eco/Balanced/Turbo profiles, tools and settings pages, overlay-permission shortcut.

Important: FPS options are preference labels only. A normal third-party app cannot force PUBG or another game to render at 144/160 FPS, overclock the phone, or bypass device/game limits. Actual FPS depends on hardware, Android and game support. This is an original inspired interface, not a copy of RedMagic's proprietary software.

Build: open in Android Studio, JDK 17, Android SDK 35, sync Gradle, then run `:app:assembleDebug`.
